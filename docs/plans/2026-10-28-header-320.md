## Cause

Below 400px the header's content box is 280px (320px minus two 20px gutters). The logo
(113.8px), the 16px header gap and the header actions (189px EN / 187.3px AR) need
318.8px / 317.1px, so the actions overflow by about 19px / 17px and the page scrolls sideways.
Measured identically on `main` before and after #13.

## Fix

Following the stylesheet's mobile-first rule (base styles for the smallest screens,
`min-width` queries add changes for wider ones): make the header slightly tighter by default,
and restore today's values from 400px up, next to the rule that already shows the globe there.

| Rule | Below 400px | 400px and up (unchanged from today) |
|---|---|---|
| `.site-header` gap | 8px | 16px |
| `.header-actions` gap | 4px | 8px |
| `.logo` height | 28px | 32px (40px from 640px, as today) |
| `.lang-switch__btn` padding | 6px 8px | 6px 12px |
| `.menu-button` padding | 6px | 8px |

This saves about 46px, leaving about 7px spare in English. Buttons stay 36px tall.

## Verification

1. At 320px (inside a 320px iframe), EN and AR, menu closed and open:
   `scrollWidth` equals the viewport width; logo, language switch and menu button sit inside
   the 20px gutters; × fully visible.
2. At 400px and 1280px, EN and AR: header measurements match `main` (no visual change).
3. Language switch and menu button still work (click both).
